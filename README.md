# ORVIA player

A clean Material 3 video player for Android. Plays your local videos in original quality, no re-encoding.

## Features
- Light / dark theme follows your device
- Playlist, add videos or a whole folder
- Swipe to seek, brightness (left) and volume (right) gestures
- Pinch to zoom, aspect ratio, fullscreen, Picture-in-Picture
- Subtitles from your phone (.srt .vtt .ass)
- Hardware decoding with FFmpeg fallback
- No login, no ads, no tracking

## Download
Get the latest APK from the [Releases](../../releases/latest) page and install it.
(You may need to allow "Install unknown apps".)
